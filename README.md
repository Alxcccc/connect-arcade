# Connect 4

A two-player Connect 4 game built with Python and [Arcade](https://api.arcade.academy/) 3.0.1.

## Features

- Turn-based gameplay with red and yellow tokens
- Turn indicator and game-over overlays
- Classic Connect 4 win detection (horizontal, vertical, diagonal)

## Install

```bash
python -m venv .venv
.venv\Scripts\activate
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
